# Vorlagen (`templates/`)

Dieses Verzeichnis ist **für wiederverwendbare Projekt-Vorlagen** vorgesehen, die künftig aus dem Visualisations-Tools-Portal heraus kopiert oder abgeleitet werden können.

Aktuell liegt hier **keine** generische `blank`- oder `hello`-Vorlage: bewusst, damit das Portal nur echte, kuratierte Projekte unter `projects/` listet und Vorlagen erst dann ergänzt werden, wenn sie fachlich abgestimmt sind.

Neue Vorlagen gehören als eigene Unterordner mit klarer Beschreibung in `README.md` bzw. später mit passendem `project.json`-Schema hierher — nicht nach `examples/` oder direkt ins Repository-Wurzelverzeichnis.
